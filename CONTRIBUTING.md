# Como contribuir

## Fluxo de trabalho (GitHub Flow)
1. Crie uma **issue** descrevendo o que vai mudar.
2. Crie uma **branch** a partir da `main`:
   - `feat/nome-curto` para novidade
   - `fix/nome-curto` para correção
   - `docs/nome-curto` para documentação
3. Faça commits pequenos com mensagens claras (padrão *Conventional Commits*):
   - `feat: adiciona filtro por linguagem`
   - `fix: corrige link quebrado do destaque`
   - `docs: atualiza README`
4. Abra um **Pull Request** para a `main` e preencha o modelo.
5. Espere a verificação automática passar e **1 aprovação** do dono do código.
6. Depois do *merge*, apague a branch.

## Papéis no repositório
| Papel | Quem | Pode fazer |
|---|---|---|
| Admin / dono | Gustavo (gust4vorss) | Tudo, inclusive configurações e segurança |
| Colaborador (Write) | Colegas convidados | Criar branches e abrir Pull Requests |
| Público (Read) | Qualquer pessoa | Ver o código, abrir issues e fazer *fork* |

## Antes de abrir o PR
- [ ] Testei no navegador (computador e celular)
- [ ] Não há senhas, tokens ou chaves no código
- [ ] Atualizei a documentação, se necessário
