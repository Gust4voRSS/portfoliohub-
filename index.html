Como este portfólio funciona

  • Projetos: a lista é lida da API pública do GitHub. Criou um repositório novo? Ele aparece aqui sozinho.
  • Destaque: vem do arquivo projetos.json, que fica guardado no repositório e tem histórico de versões.
  • Publicação: o site é hospedado no GitHub Pages. Toda mudança passa por um Pull Request antes de entrar na branch main.
  • Segurança: nenhuma senha ou chave fica no código; a página só aceita conexões com o próprio site e com a API do GitHub.
